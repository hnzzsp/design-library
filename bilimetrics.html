设计说明

给后续开发对齐用
模块一：实时数据监控 热门视频榜 + 核心互动数据表（播放 / 点赞 / 投币 / 收藏 / 弹幕 / 评论），表头标注"每30秒自动刷新"，对应后续接 B站 API 的轮询策略。
模块二：话题洞察 爆款话题榜（热度值）、上升热点榜（24h 飙升幅度）、话题热度趋势（近7天）与生命周期曲线（萌芽→爆发→平台→衰退），用于判断入场时机。
模块三：选题决策 分区热度对比 + 关键词竞争度表（热度 / 关联视频 / 平均互动 / 竞争度 / 趋势），输出"蓝海机会 / 潜力股 / 跟随热点"三类选题建议卡。
视觉规范 深色底 #0D1117 / 卡片 #161B22，B站粉 #FB7299 主强调、B站蓝 #00AEEC 第二数据色、绿 #3FB950 上升、红 #F85149 下降；中文 Noto Sans SC，数字等宽。
